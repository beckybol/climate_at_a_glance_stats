## cag_data_viz.ipynb

Python notebook grabs temperature and precipitation data from NOAA Climate at a Glance for a specific state, month, and timescale.  

Data visualizations include probability distribution for temperature, quadrant scatter plots and joint probability distributions for temperature and precipitation.  

Statistics include averages, anomalies, z-scores, probability of occurrence, and return intervals.  

## states.py

Notebook requires states.py to run. Includes dictionaries with state codes needed for the NOAA Climate at a Glance URLs. Also dictionary for 2-letter abbreviations for filenames.
